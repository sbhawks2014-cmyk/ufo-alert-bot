# 🛸 UAP/UFO Verification Bulletin: September 1, 2021 Reports

**Headline:** Multi-State UAP Activity Features High-Altitude "Tic-Tac" Formations, Rapid-Maneuver Airport Sightings, and Automated MADAR Sensor Alerts

---

### Sighting Reports

* **Location & Observed Shape:** Eau Claire, WI | Stacked Multi-Colored Lights ("Christmas Tree")
  * **Summary:** A resident near the Chippewa Valley Airport reported a bright, multi-colored object with stacked flashing lights executing rapid speed changes and vertical altitude maneuvers. The object hovered, changed directions, and suddenly vanished, performing maneuvers distinct from standard commercial aircraft or consumer drones.
  * **Credibility Score:** 6/10
  * **Identification Flag:** Drone / Unexplained Anomaly
  * **Evidence / Media:** No direct media attached.
  * **Original Link:** [NUFORC Report S164588](http://www.nuforc.org/webreports/reports/164/S164588.html)

* **Location & Observed Shape:** Newington, CT | Unknown (Automated Sensor Detection)
  * **Summary:** Automated anomaly network MADAR Node 106 registered a data trigger at 21:30 local time. No visual description or qualitative narrative was provided in the raw submission.
  * **Credibility Score:** 2/10
  * **Identification Flag:** Sensor Anomaly / Unexplained Anomaly
  * **Evidence / Media:** No direct media attached.
  * **Original Link:** [NUFORC Report S164835](http://www.nuforc.org/webreports/reports/164/S164835.html)

* **Location & Observed Shape:** Hodgkins, IL | White "Tic-Tac" / Cylindrical
  * **Summary:** An observer spotted two slow-moving, high-altitude white cylindrical objects moving in tandem across clear skies before simultaneously disappearing. Shortly after, a third identical object appeared on a similar trajectory toward Chicago before vanishing after a few seconds.
  * **Credibility Score:** 5/10
  * **Identification Flag:** Unexplained Anomaly
  * **Evidence / Media:** No direct media attached.
  * **Original Link:** [NUFORC Report S164495](http://www.nuforc.org/webreports/reports/164/S164495.html)

* **Location & Observed Shape:** Salem, OR | Changing Formations (Lines, Circle, Arrow)
  * **Summary:** Oregon State Fair attendees observed six objects shifting from random positions into distinct linear, circular, and arrow formations while drifting west. The behavioral patterns and context suggest high probability of a daytime skydiving demonstration team or coordinated balloon launch.
  * **Credibility Score:** 6/10
  * **Identification Flag:** Aircraft / Sky Divers (Likely)
  * **Evidence / Media:** No direct media attached.
  * **Original Link:** [NUFORC Report S164496](http://www.nuforc.org/webreports/reports/164/S164496.html)

* **Location & Observed Shape:** Eads, TN | Unknown (Automated Sensor Detection)
  * **Summary:** MADAR Node 32 recorded an automated detection event during early morning hours. No physical description or trajectory data accompanied this automated network trigger.
  * **Credibility Score:** 2/10
  * **Identification Flag:** Sensor Anomaly / Unexplained Anomaly
  * **Evidence / Media:** No direct media attached.
